# Atlas workflow demonstration

Author: Parusan Natheeswaran

Xenolinguist Atlas. Private accounts, versioned language evidence and comparisons you can inspect. This is the real local application.

The initial reference collection has six documented languages and seventy licensed forms. Uploads stay private and training permission is off.

Review the exact evidence and its source rights before upload. Original bytes are preserved as an immutable version.

A durable worker aligned this known English control against the references. Coverage, form resemblance and supported rules remain separate.

Repeated correspondences need independent concepts and distinct word types. Missing-form proposals also require a held-out prediction audit.

The report pins its method, original-file checksum and reference versions. Export retains the evidence, controls, audit and next useful observations.

WOLD vocabulary and WALS grammar retain their citations and licenses. Missing features and ambiguous language matches stay visible.

Desktop connections require explicit browser approval. Credentials remain in the protected main process, and each connection can be revoked.

When the host is unavailable, the interface provides a recovery path. The offline workbench remains usable.

Reviewed deletion removes versions and reports, then the worker retires their files. The original evidence-to-report workflow used zero model calls.
