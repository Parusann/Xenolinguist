## W21 proposal backend: first implementation unit

The authenticated read-only endpoint generates typed lexical, grammar and requested-observation proposals on a private profile snapshot. Profile-scoped retrieval includes source identities, annotations, linked hypotheses and counterevidence. At most four tool actions can inspect evidence and preview/test a candidate; they cannot write files or persistent knowledge. Server validation rejects fabricated references and preserves deterministic counterexamples. Structured output uses one repair attempt, a shared deadline, a declared token ceiling and a pinned local model digest. Successful responses return prompt/input hashes, retrieval payloads, typed tool traces and timing provenance.
