W03 and W04 ship together because requiring revisions without updating the existing client would break saves. Desktop draft persistence uses a stable user-data file store instead of renderer IndexedDB, because the desktop backend's random port changes the browser origin on restart. Browser use retains IndexedDB.

The W03/W04 verification baseline was 108 passing unit tests and three gated native unit checks skipped, plus six repaired browser acceptance checks and four expected failures. The packaged Windows app confirmed pending-save and text-draft recovery after the real close handshake and a new process launch. At that checkpoint, full packaged acceptance failed because IPA returned HTTP 503 from the unresolved external Transformers import; W05 has since repaired it. WAV attachment, sandbox grading/state and Unicode translation remain explicit defects. Full local test artifacts are under ignored `test-results/`; commands and limitations are recorded in [testing.md](testing.md).

No installer release or main-branch merge is implied by these implementation commits. Performance at large profile sizes, broad crash/power-loss certification, automatic corrupt-draft salvage, audio archive garbage collection, and downstream scientific evaluation remain unfinished.
